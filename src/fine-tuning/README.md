# VoQA Fine-Tuning Orchestration Module

This directory isolates the deterministic fine-tuning & evaluation grid for **InternVL-1B** and **Qwen-2B**. It is structured to decouple pipeline execution from base code, enforcing a 4-stage experimental progression for multilingual visual text comprehension.

---

## Directory Architecture

- **`data/subsets/`**: Stores deterministic 100-sample `.jsonl` benchmark subsets (GQA, POPE, ScienceQA, TextVQA, VQAv2) generated by `subset_generator.py`.
- **`python_modules/`**: Contains neural Multi-PEFT stacking components:
  - `lora_plumber.py`: Merges Stage 1 task adapters into base LLM weights and injects trainable Rank-4 language adapters.
  - `train_orchestrator.py`: PyTorch trainer wrapper intercepting DeepSpeed execution.
- **`scripts/`**: Modular bash orchestration pipeline:
  - `core/`: Environment variables (`environment.sh`) and DeepSpeed execution engine (`engine.sh`).
  - `modules/`: Stage execution modules (`task_adapter.sh`, `monolithic.sh`, `language_adapter.sh`).
  - `execute_pipeline.sh`: Unified CLI entrypoint.
- **`utils/`**: Utility scripts:
  - `subset_generator.py`: OS-agnostic dataset slicer.
  - `report_sft_table.py`: Aggregates evaluation metrics (EM, Semantic Soft Match, QAA) into paper-ready LaTeX tables.
- **Documentation**:
  - `DECISIONS.md`: Standardization rules, output hierarchy (`S1`-`S4`), and English exclusion math.
  - `THESIS_PROGRESSION.md`: Comprehensive 4-stage experimental narrative.
  - `SFT_STRATEGIES.md`: Specification of the 8 SFT loss-masking strategies.
  - `MULTILINGUAL_STRATEGIES.md`: Academic literature survey (Parrot, MLM, Deep Supervision).

## Usage

### 1. Prerequisites
Ensure you are inside WSL and the `internvl` environment is activated:
```bash
wsl
conda activate internvl
```

### 2. Dataset Subset Generation
To extract 100-sample deterministic subsets across all 5 datasets:
```bash
python src/fine-tuning/utils/subset_generator.py
```

### 3. Pipeline Execution
Run specific stages of the experimental progression via the master CLI:
```bash
# Stage 1: Zero-Shot English Task Adapters
./src/fine-tuning/scripts/execute_pipeline.sh --stage 1

# Stage 2: Monolithic Multilingual Baseline
./src/fine-tuning/scripts/execute_pipeline.sh --stage 2

# Stage 3: Pure Modularity SOTA (4 Universal + 8 Task Adapters)
./src/fine-tuning/scripts/execute_pipeline.sh --stage 3

# Stage 4: Exhaustive Modularity SOTA (32 Specialized + 8 Task Adapters)
./src/fine-tuning/scripts/execute_pipeline.sh --stage 4

# Run all 4 stages sequentially
./src/fine-tuning/scripts/execute_pipeline.sh --stage all
```

### 4. Report Results
Generate evaluation summary tables:
```bash
python src/fine-tuning/utils/report_sft_table.py --eval_dir output_tuning
```
